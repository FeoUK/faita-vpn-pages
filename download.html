Faita VPN для Windows

Офіційний інсталятор Faita VPN

Faita VPN v0.3.0-test

Універсальний інсталятор для Windows x64 та Windows ARM64. Встановлює локальний компонент Faita VPN Helper для керування системними IKEv2 VPN-профілями H-SWARM та Horyzont і взаємодії з розширенням Faita VPN у Google Chrome.

Важливо: профілі Windows повинні мати точні назви H-SWARM та Horyzont. Наявність обох профілів не обов’язкова: якщо налаштований лише один, Faita VPN працюватиме з ним, а для відсутнього профілю покаже «Не налаштовано». Якщо налаштовані обидва, Faita VPN автоматично відключає активний керований IKEv2-профіль перед підключенням вибраного.
