Faita VPN для Windows

Офіційний інсталятор Faita VPN

Faita VPN v0.3.0

Універсальний інсталятор для Windows x64 та Windows ARM64. Встановлює локальний компонент Faita VPN Helper для керування системними IKEv2 VPN-профілями H-SWARM та Horyzont і взаємодії з розширенням Faita VPN у Google Chrome.

Важливо: підтримуються системні IKEv2 VPN-профілі Windows з точними назвами H-SWARM та Horyzont. Наявність обох профілів не обов’язкова: якщо налаштований лише один, Faita VPN працюватиме з ним, а для відсутнього профілю покаже «Не налаштовано». Якщо налаштовані обидва, потрібний VPN можна вибирати та перемикати безпосередньо у розширенні.

Встановлення

  1. Налаштуйте у Windows один або обидва системні IKEv2 VPN-профілі з точними назвами H-SWARM та Horyzont.
  2. Завантажте та запустіть інсталятор Faita VPN. Він автоматично встановить Faita VPN Helper і зареєструє його для Google Chrome.
  3. Встановіть або оновіть розширення Faita VPN у Chrome Web Store. Якщо воно ще не встановлено, інсталятор запропонує перейти до Chrome Web Store.
  4. У Chrome відкрийте меню «Розширення» та закріпіть Faita VPN на панелі браузера.
  5. Натисніть значок Faita VPN і виберіть потрібний профіль. Якщо інший керований IKEv2 VPN активний, Faita VPN відключить його перед підключенням вибраного.

Індикація

Зелений значок — вибраний VPN працює та контрольний ресурс доступний; червоний — VPN вимкнений або Helper/з’єднання недоступні; помаранчевий — виконується підключення чи відновлення або VPN підключений, але контрольний ресурс тимчасово недоступний. Наведіть курсор на значок, щоб побачити активний VPN-профіль.

Faita VPN підтримує автоматичне відновлення вибраного VPN після тимчасової втрати Інтернету. Явне відключення VPN користувачем припиняє автоматичне відновлення.
