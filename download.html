Faita VPN для Windows

Офіційний інсталятор Faita VPN

Faita VPN v0.4.0

Універсальний інсталятор для Windows x64 та Windows ARM64. Встановлює Faita VPN Helper для керування системним IKEv2 VPN-профілем Horyzont та взаємодії з розширенням Faita VPN у Google Chrome.

Встановлення

  1. Налаштуйте у Windows системний IKEv2 VPN-профіль з точною назвою Horyzont.
  2. Завантажте та запустіть Faita VPN Universal Setup. Архітектура x64 або ARM64 визначається автоматично.
  3. Після встановлення Helper перейдіть на сторінку Faita VPN у Chrome Web Store та натисніть «Додати в Chrome».
  4. Обов’язково закріпіть розширення: натисніть кнопку «Розширення» (пазл) праворуч від адресного рядка та виберіть «Закріпити» біля Faita VPN. Після цього значок Faita VPN постійно відображатиметься на панелі Chrome.
  5. Натисніть значок Faita VPN та використовуйте «Підключити» / «Відключити».

Діагностика

Розширення відображає стан Інтернету, VPN Horyzont, DNS користувача, внутрішнього DNS Faita та доступність ресурсів Faita 170 і Faita 222. Якщо DNS поточного підключення користувача не працює, Faita повідомить про це окремо, а внутрішні ресурси продовжать використовувати DNS Horyzont під час активного VPN.
