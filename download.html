Faita VPN для Windows

Офіційний інсталятор Faita VPN

Faita VPN v0.2.5

Універсальний інсталятор для Windows x64 та Windows ARM64. Встановлює локальний компонент Faita VPN Helper для керування системним IKEv2 VPN-профілем H-SWARM та взаємодії з розширенням Faita VPN у Google Chrome.

Важливо: системний VPN-профіль Windows повинен мати точну назву H-SWARM.
